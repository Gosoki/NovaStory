## 1. 三段创意（题目是系统随机给的，看到哪个用哪个）

三段**故意写成三种不同形式、三种不同长度**——演示的重点是「写多写少、什么形式都行」，
不是给学生一套范本。硬性下限只有 8 个字。

### 题目 A ·「捡到的失物（别人掉的东西）」
> 情境：在路上捡到别人掉落的小东西。是打开看看、拿去归还，还是——。

**写法：粗略型（只说发生了什么）· 23 字**

```
捡到一个钱包，犹豫了三秒，还是追上去还给人家。
```

---

### 题目 B ·「最后一口（分享还是独享）」
> 情境：眼前只剩最后一口喜欢的东西——短短几秒的拉锯。是分给别人，还是自己吃掉。

**写法：细写型（像个短脚本）· 54 字**

```
①桌上剩最后一块，两双筷子同时停住。②两个人对视，谁也不先动。③最后一起伸手，筷子撞在一起。轻松一点的调子。
```

---

### 题目 C ·「陌生街道的第一步」
> 情境：降落在陌生的街道，迈出第一步。是看地图、循着气味走，还是开口问路。

**写法：只写基调型 · 36 字**

```
想要那种一个人站在路口、有点茫然又有点兴奋的感觉。最后随便挑了一条路走。
```

## 2. 三种做法各自还要动什么

| 做法 | 出稿后你要做的 | 现场怎么演 |
|---|---|---|
| **A** 一句话直接出（代码 C） | 什么都不用做，只能提交 | 直接点「提交」，说明「这一版就是最终版，改不了」 |
| **B** 先出一版再改（代码 D） | 在反馈框里写要改什么，可以改很多次 | 用下面的话术改一次就够，别改太多轮，费时间 |
| **C** 先答几道题再出（代码 E） | 生成**前**先答 5–7 道选择题 | 每题点一个选项就行，**不用打字**；也可以点「交给 AI」 |

**B 的修改话术（挑一句用）**

```
节奏太慢了，第一个镜头缩短一点。
```
```
最后一个镜头我想要个特写。
```
```
再搞笑一点，结尾收得干脆些。
```

**C 的引导问答**：一次只出一题，点选项即可。想快就每题点第一个选项，或点「交给 AI」。
遇到「或者自己写」的输入框可以跳过。

## 3. ⛔ 演示时的两条硬约束

**① 三种做法不能褒贬。**
演示 B 时别说「你看还得改，多麻烦」，演示 C 时别说「这个更准吧」。
学生等下就是被试，你现在给哪种做法贴标签，就是在压他们自己的评分。
**标准说法：「三种都会碰到，哪种更顺手你们自己感受，我们也不知道答案。」**

**② 你输入的创意，学生会照着模仿。**
这是没法完全避免的锚定效应，所以上面三段刻意写得平淡、常见、没有巧思。
演示时补一句：**「我这是随手写的，你们别抄我，写你自己想到的。」**

> 想彻底避开锚定，把演示挪到学生做完之后再讲——但那样就失去了「先看懂再动手」的作用。
> 现在这个折中是：**演示形式，不演示创意**。
