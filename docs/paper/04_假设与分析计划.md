## 1. 假设表（v3，预注册前锁定）

| # | 假设 | DV | 方向 | 主对比 / 检验 | 性质 |
|---|---|---|---|---|---|
| **H1** | 意图保真 E > D > C | **保真复合**（想象匹配 + 违背反向 + 逐镜头 mine 率 + embedding Δ） | E 最高 | **E−D（主）** / E−C / D−C，Holm | 确认性 |
| **H2** | 心理所有权 E ≥ D > C | **所有权复合**（own1-3，含 possession + self-investment） | E 不低于 D、均 > C | E−D / D−C | 确认性 |
| **H3a** | 事后返工 E < D | `effort_composite` = mean z(log1p(n_ai_rounds, hand_edit_chars, t_postgen)) | E 更少 | E−D | 确认性 |
| **H3b** | 努力再分配：E 事前投入前移且总投入不劣 | `t_pregen` / 三口径总投入 | E 前移 | 描述 + E−D | 确认性 |
| **H4** | 质量非劣：E 不劣于 D | 结构完整度（客观下界） | \|E−D\| < 预注册 SESOI | **TOST** | 确认性 |
| **H5** | 剂量-反应：E 内事前投入↑ → 保真↑ | 保真 ~ 事前投入 | 正 | **被试间 OLS**（每被试仅 1 个 E 轮） | 探索→**已升为预注册确认性次分析**（承接归因） |
| **H6** | 同质化：条件影响产出趋同度 | 组内 CR / 语义 z vs 机器地板 | C 更同质？ | 组级 | **探索** |
| **H7** | 反向分支：满意度与所有权分离（新手或偏好 D） | satisfaction × 所有权 | 解离 | 象限判定 | **反向/悬念**（Knijnenburg 2011 / Slovic 1995） |

> ⚠️ **H3a 与 H3b 不能合并**——旧幻灯片曾把两者压成一个 H3，后已拆回。H3a = 事后 E<D（可能撞地板），H3b = 再分配（E-only，不依赖 D 的返工空间）。

**H5 的规格修正（重要）**：每被试仅 1 个 E 轮 → **无法被试内中心化**，实为**被试间关联（OLS）**，受被试间混淆限制；报 CI、定位为机制探索而非因果。（旧文档写的「被试内中心化」是规格-实现矛盾，已作废。）

**归因链**：H5（剂量-反应）+ **D 反馈内容编码（图4）** 一起承接「为什么 E 有效」的归因，两者均为**预注册确认性次分析**（从探索升级），因为主对比 D-vs-E 是工作流包层的多变量对比。

## 2. 主要终点（A4 拍板，pilot 后预注册锁定）

**主要终点只有两个**（`prereg.PRIMARY_ENDPOINTS`）：

### 2.1 保真复合 `fidelity_composite`
= 想象匹配 + 意图违背（**反向**）+ 逐镜头 mine 比例 + **创意↔终稿 embedding 相对基线 Δ**
各成分**被试内 z 标准化后取均值**（公式进预注册）。

- **pilot 验收规则**：embedding 与其余三成分方向一致且收敛相关达标（**建议 r ≥ .3**）→ 留；不达标 → **降次要**，复合缩为三件套。
- 这也是 JP2（日语短文本 embedding 可比性存疑）的处置。
- **主观三腿先平均、再与 embed 各半**（预注册复合定义时锁）。
- 缺失数据规则在预注册时锁定。
- 逐镜头 `mine_ratio` 当**序数**处理 / 分条件报；C 条件的回溯归因考虑不入池。

### 2.2 所有权复合 `ownership_composite`
= own1-3 均分（**soa1-2 次要，但都保留、都报告**）。

- own3 = self-investment facet，**possession（own1/2）与 self-investment 分报**。
- 若 pilot 显示 own 有测量问题（日语 α 崩 / 天花板），可在**预注册前**改判为 soa 或双主终点——**预注册锁定后、正式数据到手后不可再换**。
  （把「哪个好用用哪个」合法化为 **pilot 决策**而非正式数据决策。）

### 2.3 次要终点 `prereg.SECONDARY_ENDPOINTS`
`satisfaction`、`effort_composite`、`post_investment`、`total_investment`。

**族错误控制**：两个主复合上做 FWER；次要 / 探索**门控其后**（正式族在预注册 SAP 锁定）。

## 3. 统计分析（预注册后执行）

1. **主分析**：每个 DV 拟合 LMM
   ```
   DV ~ 条件 + 题目 + 顺序位置 + (1 | 被试)
   ```
   计划对比 **E−D（主）**、E−C、D−C，**族内 Holm 校正**。
2. **稳健性**：Wilcoxon 符号秩（配对）；Likert 单题用 **CLMM**（序数）复核；计数类（轮数 / 手改次数）用**负二项**混合模型；时长 log 变换。
   - 单终点 `n_ai_rounds` 的确证检验用负二项 → 预注册 SAP 锁。
3. **非劣（H4）**：**TOST**，等价界用**预注册的绝对 SESOI**（⚠️ 不可用数据依赖的 `bound_sd × sd`——已修正）。
4. **剂量-反应（H5，E 内）**：保真/所有权 ~ 事前投入（自填率、答题净时、1−AI 代答率）；**被试间 OLS**，报 CI。
5. **敏感性**：
   - 加总时长协变量（正面处理时间混淆）
   - 仅第 1 轮的**组间**分析（防残留）
   - 剔除非 novice / attention 失败 / straightline / fallback 轮
   - 更换 embedding 模型
   - intent 长度 / 维度覆盖特征作协变量（全事后可算，接 `pilot_check`）
6. **探索**：同质化（置换检验 + 机器地板）、D 反馈编码统计、中介（事前投入 → 违背↓ → 所有权↑，**仅探索**）。
7. **功效**：`analysis/power_sim.py`——**与主分析同构的 LMM + Holm 功效**（不是配对 t）；已报 N=36 → 80% 功效 dz ≈ 0.48。
   预注册前跑 ρ ∈ {.3, .5, .7} 敏感性，**报功效曲线而非单点**；若 novice 子集为主分析人群，需另算子集（更小 N）功效曲线。

### 3.1 数据清洗硬规则

- **dev 被试必须排除**：`v3.load` + `pilot_check.check_novice` 按 `screening_json.dev` 排除（曾实测 6 trials 中 4 条是 dev 走查行）。
- 不完整数据（未走到 trial_submit / final_survey 的 in_progress 被试）**弃用不进任何分析**。
- 重做轮取「中签 attempt」（含非空 `trial_id` 的事件组）。

## 4. D 反馈内容编码（图4 的机制链）

把 D 的 `revision_requests` 按「**是否落在 E 的引导维度上**」编码——若 D 用户事后修的**恰是 E 事前问的**，机制闭环。

- **编码者**：研究员单编码 + **LLM 作第二编码者**，报**人-机一致性**，Limitations 说明（原「两名编码者 + 一致性」因无外部人力改此备选）。
- codebook：`revision_requests` → 引导维度（psychology / turning_point / key_shot / tone / ending / sound / detail / other）。⚠️ **codebook 终稿待定**。
