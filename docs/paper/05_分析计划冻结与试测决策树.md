## 0. 核心心态：这研究为什么「不会翻车」

**不是因为 E 一定赢，而是因为每一种结果都预先想好了怎么讲。** 只要把主张退守到——

> **E 在保真/多样性上「不劣于」D，且把努力前移（事前投入↑、事后返工↓），并保住/提升作品的心理所有权**

——那么即使 E 在保真上不占优，论文依然成立（灵魂句降为「受本研究启发的设计主张」，明确适用边界）。
**真正的失败只有一种：结果不好看、又没有事先声明的备选叙事。** 本文就是消灭这一种。

## 1. ⛔ 不做第三方预注册 —— 改为「内部冻结」（B3 拍板，2026-08-03）

### 1.1 决定

**不向 OSF / AsPredicted 提交预注册。** 替代做法 = **内部冻结分析计划**。

（参考：预注册本身 = 收数据前把「假设 / 设计 / 样本量 / 主要终点 / 怎么算 / 什么算支持」交第三方盖时间戳，核心是**承诺 + 不可篡改的时间戳**，用来锁死研究者自由度、防事后挑好看指标（p-hacking / HARKing）。它不是审批，成本约 1-2 天、零金钱；IUI/C&C 都不是投稿门槛。）

### 1.2 替代做法：内部冻结（**照做，不要省**）

正式采数开始前，把下面三样一次性固定并**纳入版本管理**：

1. `analysis/prereg.py` —— 阈值 / novice 定义 / **SESOI** / 终点层级 / 复合公式的单一真源
2. 本文件的**试测决策树 + 四象限解释矩阵**（§2、§3）
3. [04 假设与分析计划](04_假设与分析计划.md) 的假设表与统计流程

然后 `prereg.as_dict()` **dump 成带 hash 的文件**，连同 **git commit** 一起留档。
这样仍能说：**「分析计划在见到任何数据之前就已确定，并纳入版本管理」** —— 这是真话，也是最主要的抗 HARKing 价值来源。

### 1.3 ⚠️ 代价（要知道自己放弃了什么）

- **强度弱于第三方预注册**：自己的仓库、自己能改历史，外部无法独立验证时间戳。
- **写作与答辩措辞硬约束**：
  - ⛔ **不得写 "preregistered" / 「事前登録済み」/「予登録」**
  - ✅ 可以写 "the analysis plan was fixed and version-controlled prior to data collection (not third-party preregistered)"
- **Limitations 必须有一条**：无第三方预注册，研究者自由度的控制弱于预注册研究（见 [08 §9](08_论文写作与投稿.md)）。
- **答辩会被问「你怎么保证没有 HARKing」**：答法 = 展示冻结产物 + git 历史 + 本文的事前声明后手树，并**坦承这弱于 OSF 预注册**。诚实划界比含糊其辞更能得分。
- `docs/index.html` 的「事前登録」措辞**已全部改掉**（结び页、分析页、手法页）。

### 1.4 pilot 的含义（重要）

**不做正式功效 pilot**，但**原型定型后会先找几个人小规模试测（排雷 + 校准阈值）→ 无问题即大范围**。因此：

- 主要终点仍应**据文献 + 源量表先验锁定**；
- ⛔ **别用小试测效应量做功效分析（有偏）** → 改用 **SESOI + 已定 N 做 a priori power**；
- judge / 阈值可用**小试测或非被试样例数据**校准，并在冻结产物中声明。

### 1.5 SESOI 已锁定（B2 拍板，2026-08-03）

**`prereg.SESOI = 0.10`** —— 单位是 **DV 原始单位**；H4 的主质量 DV = 结构完整度（0-1 比例），故 **0.10 = 10 个百分点**。

> 读法：「E 的结构完整度比 D 低 **10 个百分点以内** → 判定为『质量无实质损失』」。

为什么是 0.10：0.05 在 N≈36 下几乎不可能通过（等价界过窄 = 永远测不出等价，等于自断非劣性主张）；0.15 太宽，会被问「差 15 个点也算不劣？」；0.10 ≈ 每 10 份稿子里多 1 份结构不全，对「客观下界」型指标是可辩护的实质阈值。
**这是 a priori 设定**（设定时 N=0，未见任何真实数据）。`stats.tost` 已实测：真差 3 个百分点 → 判等价 ✓；真差 20 个百分点 → 判不等价 ✓。

⚠️ **功效换算**：`power_sim` 以配对 dz 工作，而 SESOI 是原始单位 → `dz ≈ SESOI / SD(配对差)`。SD 未知（无功效 pilot），故报**功效曲线**而非单点；真数据到手后用实测 SD 回算写进结果节。**主分析人群 = novice 子集（B1）→ 需另算子集功效曲线。**

## 2. 四个生死问题 × 优化 / 检测 / 后手

### ① D 地板效应 —— 返工有没有空间
- **危险**：新手拿到 AI 稿基本不改 → D 返工 ≈ 0 → 招牌图「E 比 D 少返工」**物理无空间可减**，最有传播力的数字（对标 APE 迭代 −39.5%）结构性 null。
- **优化（现在能做）**：D 看稿页已明示 3 种改法；可让首版 prompt 产出「好但明显可改」的稿以留出空间；**招牌叙事不押注单一「返工↓」**。
- **检测**：`pilot_check ①` —— D 零返工比例 > 60% = 🔴，30-60% = 🟡（`prereg.D_FLOOR_ZERO_*`）。
- **后手 A**：招牌从「返工↓」→ **「保真/所有权↑ + 努力再分配」**（E 的事前投入是 **E-only**、不依赖 D 的返工空间，纯行为日志就能画图3）；且**「新手被动接受默认输出」本身就是支持动机的发现**——报 D 的 acceptance 率（拿到就交的比例），把 null 转成正向证据。

### ② C 天花板 —— 一发生成是否已够贴合
- **危险**：意图基准只有 1-2 句，信息量太薄，C 直出可能已高度贴合 → E>D>C 的保真差被压扁、检不出（尤其日语短文本 embedding 可能主测用词重叠）。
- **优化**：**逐镜头标注（mine/ai_ok/ai_against）+ imagine_match 比「embedding-to-1-2 句」更细、更抗天花板**；意图基准生成前锁定（防循环测量）。
- **检测**：`pilot_check ②` —— C 的 imagine 均值 ≥ 6 且 SD < 1 且 E−C < 0.3 = 🔴（`prereg.C_CEIL_*`）。
  ⚠️ 加**保真项判别方差**交叉守卫（防中点压缩掩护天花板）。
- **后手 B**：embedding 保真**降次要**（A4 决策树已埋此预案），逐镜头 + imagine 升为主保真；主张改 **「E 在保真上不劣于 C，但所有权/努力再分配更优」**（与灵魂句完全一致）。并列 chrF / 关键词落地率暴露「相似度到底测的是什么」。

### ③ novice 占比不足 —— 人群卖点站不站得住
- **危险**：招到的大学生里真新手太少 → 处理效应被稀释；而「零基础新手」是**唯一真正区隔于 APE 的人群要件**，占比不足则声明超出数据。
- **优化**：**招募端加门槛是最大杠杆**——广告直接面向「从没做过视频/分镜、没相关专业背景的人」；app 已记录 5 项操作化。
- **检测**：`pilot_check ③` —— 达标 novice < 40% = 🔴，40-60% = 🟡（`prereg.NOVICE_SHARE_*`）。
- ✅ **已拍板（B1, 2026-08-03）**：预注册把 **「仅 novice 子集」前置为主分析群体**（全样本作稳健性），经验者单列做 H8 对比/调节分析。
- **后手 C（占比不足时）**：措辞从「novice-专属」弱化为 **「以 novice 为主体样本 + 经验作调节变量」**，不让声明超出数据；同时**预算 novice 子集的功效**（N 更小，dz 需更大）。若 <40%，另两条退路 = 招募端加软门槛（杠杆最大）／**在冻结时**把定义放宽为 4-of-5。

### ④ 量表信度 / 中点应答 —— 所有权测不测得准
- **危险**：own α 崩 / 日本被试爱选中点压缩方差 → 心理所有权（主终点）失去区分力。
- **优化**：soa 已换**已验证的 J-SoAS SoPA**；**所有分析用被试内差分**（自动消掉中点/谦逊的应答风格偏差）；认知访谈（5-8 人）查 own 三题理解一致性。
- **检测**：`pilot_check ④` —— own1-3 Cronbach α < 0.6 或 soa1-2 相关 r < 0.3 = 🔴（`prereg.OWN_ALPHA_FLOOR` / `RELIABILITY_*`）；并看中点应答比、总 SD。
- **后手 D**：所有权主终点改用 **J-SoAS SoPA（soa）**，own 降次要、两者都报（A4 已把「pilot 决定 own vs soa」合法化）；own 若 α 崩考虑补第 4 题。

## 3. 元后手：四象限解释矩阵（无论结果如何都可发）

> 主对比 = E vs D（保真复合、所有权复合）。四种落点都有归宿：

| E 的保真 | E 的所有权 | 叙事 | 对话对象 |
|---|---|---|---|
| ↑ | ↑/≥ | **主假设成立**：生成前引导既提保真又保所有权 | APE（推广到叙事 + 所有权）、Maier |
| ≈（不劣） | ↑ | **退守主张成立**：保真不劣但所有权/努力再分配更优——正是灵魂句 | Timing Matters、He、Joshi |
| ↑ | ↓ | **帕累托权衡新发现**：引导提保真却压所有权（塑造 vs 提取？） | Slovic、Knijnenburg（H7） |
| ≈ | ≈ | **「把工作量前置」的诚实结论** + 新手行为画像（D 的 acceptance、E 的 is_custom/ai_decided 剂量） | 方法学 + 设计启示 |

**满意度与所有权若分离（H7）**：新手嫌引导麻烦 → 满意度 D>E 但所有权 E>D，同样可发表（Knijnenburg 的反向证据得到复制）。
