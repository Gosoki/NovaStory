## 🔴 ① novice 是「主分析人群」还是「协变量」？（三处说法冲突）

| 出处 | 现在写的 |
|---|---|
| `docs/index.html` 手法页（**对外口径**） | 「初心者（**経験は共変量**／誰でも参加できる）」 |
| `analysis/prereg.py` NOVICE_DEF 注释 | 「录而不 gate，**是预注册主分析人群**」 |
| [05 §2③ 后手 C](05_预注册与试测决策树.md) | 「预注册把**仅 novice 子集前置为主分析群体**（而非事后稳健性）」 |
| 深度评审 #3 | 5 项严格 AND、录而不 gate、却是预注册主分析人群 → **需你拍板** |

**为什么必须先定**：它同时决定 ①招募广告文案 ②预注册的主分析人群 ③功效计算的 N（子集更小 → 需要更大 dz） ④「零基础新手」这个**唯一区隔于 APE 的人群要件**能不能声明。

**三个选项**：
- **A. novice 子集 = 主分析人群**（全样本作稳健性）。卖点最强，但要按子集重算功效、且要超招募到子集也够 N。
- **B. 全样本 = 主分析，经验作调节变量**（= 幻灯片现在的说法）。功效安全，但「novice-专属」的声明必须整体降级为「以 novice 为主体」。
- **C. 放宽 novice 定义**（5 项严格 AND → 4-of-5），提高达标率再走 A。

**需要的输入**：试测实测大学生池的 5 项通过率（`pilot_check ③`）。**建议**：先跑试测拿占比，再在 A/C 之间选；无论选哪个，`power_sim` 都要加 novice 子集功效曲线。

## 🟡 ⑩ 可延后（不影响被试跑通，数据洁净/边角）

- **E 引导数量约束只靠 prompt**：固定 3 维 / 5-7 问 / 追问 1-3 问 / 每问 3-4 选项**没有实时校验**，模型偏离会原样呈现；问答数据已全落库可事后审计。加校验有误杀风险（偏离→误触发 fallback），**暂观察试测实测**。
- **E 追问 prompt 不带历史问题** → 追问轮可能重复问过的问题（概率低，模型能看到当前稿）。
- **LLM 返回空串（无异常）时无错误提示** —— C/D 只剩裸重试按钮、E 终稿/D 修改静默无反应（罕见）。
- **多标签页同 token 并发无守卫** —— 两个标签页各自推进同一被试会互相覆盖（单人单坐的实验，现实概率极低）。
- **final_survey 提交 → 置 done 之间断线**，续接会让被试重填总问卷（秒级窗口）。
- **杂项 nit**：DB 连接用完没显式关；JSON 模式没用官方 `response_format`；逐镜头三标签语义略重叠；「15秒・3カット」硬/软约束没向被试讲清；历史面板默认展开占首屏；进度条在 final_survey 阶段不显示（可接受）；consent + 管理员两个语言器同时渲染显示可能不一致（仅管理员）；`reset_for_next` 后研究员面板仍开着；`load_topics` 对损坏文件静默回退种子主题（不崩但不告警）；C/D 生成中杂散 rerun 会整段重新生成（无幂等守卫，未观测到实际触发）。
