## 2. 数据管理与被试合规

### 2.1 数据都有什么（敏感度分级）

| 数据 | 存哪 | 敏感度 | 备注 |
|---|---|---|---|
| 人口学/筛查（年龄段·专业·AI 使用等） | `participants.demographics_json` / `screening_json` | 低-中 | **以 index 存储、语言无关**，非自由文本；最小化采集 |
| 基线协变量（aiexp/trust/own_trait） | 同上 | 低 | 刻度值 |
| **被试自由文本**（创意 intent / D 的反馈 / 手改稿 / final_survey 留言） | `trials.*` / `participants.final_survey_json` | **中-高** | 可能无意中含可识别信息 → §2.4 |
| AI 生成的每版脚本 | `trials.script_versions` | 低 | |
| 量表作答 / 逐镜头标注 | `questionnaires.*` | 低 | |
| **被试选择的语言** | `participants.lang` | 低 | ja/zh/en，同意页选一次。已进分析管线与监控台（2026-08-03） |
| 行为事件流（时间戳/动作/token） | `events` | 低 | |
| 续接句柄 token | `participants.token` | 中 | 进网址 `?t=`，是会话恢复凭证，非身份 |
| 完成码 | 运行时生成 | 低 | 由 participant_id 派生 |
| 分镜插图 | `data/storyboard_images/{被试}_{轮次}/` | 低 | 已 gitignore |

**不采集**：姓名、学号、邮箱、IP（Streamlit 默认不落库）、任何直接身份标识。
`participant_id` = 自增整数，与真人身份之间**无映射表**（**匿名**而非假名）。

### 2.2 存储

SQLite 单文件 `data/novastory.db`（WAL 模式），自有服务器原地持久，不用外部 DB。

### 2.3 ⚠️ 第三方数据流出：被试文本会发送到 OpenAI

**这是最容易被忽略的合规点。** 被试写的创意、手改稿、D 的反馈，都会作为 prompt **发送到 OpenAI API**（`core/llm.py`）。即：

- 被试的原创文本会**离开你的服务器、经过第三方（OpenAI）**；
- **同意书必须明确告知**「你输入的内容将由外部 AI 服务（OpenAI）处理以生成脚本」；
- 参考 OpenAI API 数据政策（API 数据默认不用于训练、有限期留存），写进同意书 / 数据管理说明；
- **APPI（日本个人情报保护法）数据越境**：同意书须达越境提供的粒度——**国名 / 保留期 / 是否用于训练**。
  ✅ **已实装（B4, 2026-08-03）**：`consent.body` 三语新增「外部AIサービスの利用」段，写明 **OpenAI 社（米国）**、默认不用于训练、最长 30 天后删除、并要求被试勿填可识别信息。
  **可选加固**：申请 **OpenAI zero-retention 端点**，则「最多保留 30 天」可改为「保持しない」。
- **伦理审查**：✅ **已拍板（B4, 2026-08-03）不提交伦理审查**；上述告知义务照做（与是否送审无关）。

### 2.4 自由文本的可识别信息风险

被试的创意/反馈/留言是自由输入，**可能无意中写入真实人名、校名、具体经历**。处置：
- 同意书说明「请勿填写可识别他人或自己隐私的真实信息」；
- 分析/发表前对自由文本做一遍**人工去标识扫查**（尤其要进论文定性框的摘录）；
- 定性摘录发表前改写/打码。

### 2.5 数据用途与保留

- **仅用于本研究**（学位论文 + 投稿 + 公开数据集若做则匿名后）。
- 不完整数据（未走到 trial_submit / final_survey 的 in_progress 被试）**弃用不进分析**，但匿名记录可留档。
- 保留期：按学位/投稿要求（通常成果发表后数年），到期后处置。

## 3. 采数期监控（研究员后台「🗂 数据管理·监控」）

**每天看的：**
- 概览卡片：完成 / 进行中 / 筛除 / **novice 占比** + 目标 N 进度条
- **各 seq 完成数**（18 格补全）+ 目标 N/18 提示 → 判断**超招募停止规则**是否达标
- 条件×题目计数平衡热力表、每日完成数、各条件主观均值
- **数据健康块**：解析失败率（`parse_ok=0`）/ LLM 报错率 / 引导降级率（`fallback`）/ 生成延迟中位·95%
  ⚠️ 绿色进度条会掩盖 `parse_ok=0` 腐蚀，**必须单独看数据健康块**。
- **语言构成**（2026-08-03 新增）：正式研究是 ja；出现 zh/en 会**变成黄色告警**——说明是研究员测试或脱离协议的会话，**当场就要发现**，不能等分析时才看到。

**试测期额外监控**（B3）：
- 轮数 / 净用时分布（验证 10-15 分钟软目标是否现实）
- **E 第 1 轮 AI 代答率 > 50% 预警**（若过高，补充维上限 4→2）
- D 的 AI 通道使用率（= D 地板效应的先兆，见 [05 §2①](05_分析计划冻结与试测决策树.md)）
- 引导步实测延迟
