## 2. Abstract 骨架（6 句）

① 使用生成式 AI 创作时，人往往说不出专业意图（缺乏影视经验者尤甚），AI 按默认值补齐 → 产出不贴心中所想；
② 当前主流工作流是「先生成再修改」，而「先问清再生成」（类 AskUserQuestion）在创作域无对照证据；
③ 我们构建 NovaStory，在分镜创作中实现三条工作流（一次成型 C / 生成后修改 D / 引导后生成 E）；
④ N ≥ 36 被试内实验（主分析人群 = 全样本；创作经验作事后探索性分层），联测意图保真、心理所有权、修改行为；
⑤ 主要发现（留空：E vs D 的保真/所有权/返工结果）；
⑥ 启示：AI 创作工具应把意图澄清前置。

## 3. Introduction（1.5 页）

- 3.1 背景钩子：创作民主化 vs **「提示鸿沟」**——人往往不会把主角欲望/转折/画面写进 prompt（Zamfirescu-Pereira 2023）；AI 默默用默认值补齐。
- 3.2 现状工作流 = 生成后修改（ChatGPT 范式）；新范式 = 生成前提问（工业界已普及：Deep Research、AskUserQuestion；**学术对照证据缺位**）。
- 3.3 **灵魂句**：好的 AI 共创应在生成之前规避问题，而非生成之后反复返工。
- 3.4 研究问题（RQ1-3）。
- 3.5 贡献三条（与 [01 §3](01_研究定位与主张.md) 收窄版一致，以 §3.6「不主张」段为**硬约束**）：实证 / 系统（NovaStory 三工作流平台）/ 证据（对工具设计的启示）。
- 3.6 **「What we do NOT claim」一段**（澄清提问 / 时机操纵 / 所有权测量各自已有先例，引 APE / Maier / Timing Matters）。
- ⚠️ **同质化「再解释」不进 Intro 主论证链**——降为讨论级猜想 / 探索性 H6（见 [01 §8](01_研究定位与主张.md)）。可引同质化文献作背景，但不主打。

## 9. Limitations（诚实清单，逐条写）

1. **D vs E 双差异**（工作流级对比，非单变量；已用框架与剂量分析缓解）
2. **事前投入带来的时间/注意混淆**（总时长协变量敏感性）
3. **新颖效应与需求特征**（主观指标可能偏 E；靠客观行为对冲）
4. **单模型 / 单域 / 单语言 / N ≥ 36**
5. **LLM-judge（盲评保真）无人评锚定且单家族**（全用 OpenAI ×3；以 ICC 自一致性代偿 + 引 Zheng 2023 / TTCW 界定适用域；仅作次要 / 收敛证据。**质量维不用 LLM 评**——A1 审美 rubric 已弃）
6. **无外部真人保真锚** —— 主保真是被试自评 + embedding Δ。答辩答法：意图保真的正确裁判是被试本人（外部人不知其心中像）。
7. **选项可能塑造而非纯提取意图**（Slovic；报 `is_custom` 率并讨论）
8. **意图基准仅 1-2 句**（天花板效应风险；靠逐镜头标注细化）
9. **量表未经独立预试**（无 pilot → α/CR 事后报；own1-3 为自译改编，非验证过的日语量表）
10. **应答风格主要靠被试内差分控制**（未加反向项）
11. ⚠️ **E 的引导提示一律以「新手」为前提** —— `core/prompts.py` 的 zh/en/ja 三语引导提示都写死了
    「用户是没有任何影视经验的新手」（zh:385 / en:403 / ja:432，另 ja:444 同一前提）。主分析人群改为全样本后，
    **有创作经验的被试收到的引导强度可能不匹配**（问得太基础）。刺激材料已进 `freeze_prereg.HASHED_FILES`，
    采数前后都不改；这条作为设计限制如实写出，并与经验分层的探索性结果对读（2026-09-07）。
12. ⚠️ **问卷阶段可见分镜插图** → 保真/所有权 DV 含视觉成分；被试内设计使其在 C/D/E 间均等（不偏 E−D），但改变构念解释（见 [02 §6](02_实验设计.md)）
12. **novice 不设入口门槛**（随机招募）——**主分析人群 = 全样本**（2026-09-07 拍板）；novice 子集与经验调节均为**事后探索性**，分节呈现并标注 exploratory。答辩若问「为什么不只看新手」：人群从来不是本研究的差异化要件（`01 §3.1` 五要件里没有它），而 APE 已报告经验不调节效应；全样本主分析功效更足、外部效度更好，经验水平照常测量并如实报告
13. **LLM 输出非逐字可复现**：实测 gpt-4o-mini 在 temperature=0 + 固定 seed 下 5/5 次输出仍不同（`system_fingerprint` 相同）。我们钉死模型日期快照与参数、每调用发 per-trial seed 并记录 `system_fingerprint`，保证的是**过程可复现与漂移可检测**，不是 bitwise 复现。（分镜配图用的 `gpt-image-1` 更无日期快照可钉；非 DV。）此实测可进方法附录
14. **无伦理审查**：本研究未提交研究科伦理审查；知情同意、数据最小化、外部 AI（OpenAI，美国）处理告知、自由文本去标识流程均按规格执行
15. **无第三方预注册**：分析计划在采数前确定并纳入版本管理（`analysis/prereg.py` 的 hash 化 dump + git commit），但**未向 OSF 等第三方预注册**，研究者自由度的控制强度弱于预注册研究。⛔ 全文**不得使用 "preregistered" / 「事前登録」**，只写 "the analysis plan was fixed and version-controlled prior to data collection"

## 11. 答辩火力点（多专家评估：裁决 = 勉强够 / conditional pass）

> 纸面设计超合格线，「够」押在**未采数据**上（N=0）。以下是评估集中开火的地方与备好的答法：

| 火力点 | 答法 |
|---|---|
| **无真人评审锚** | 意图保真的正确裁判是被试本人（外部人不知其心中像），故被试自评是恰当锚；引 TTCW 说明为何不用 LLM 评创意；诚实写进 Limitations |
| **D-vs-E 工作流级混淆** | 承认是工作流包对比，因果不落单变量；由 H5 剂量-反应 + D 反馈内容编码（图4）承接归因，两者已升为**事前声明的确认性次分析** |
| **新手不设门槛** | 5 项操作化全程记录并如实报告样本构成；主分析人群 = 全样本（2026-09-07 已拍板），novice/经验切分仅作事后探索性分层 |
| **意图基准 1-2 句天花板** | 逐镜头标注 + imagine_match 比 embedding-to-1-2 句更抗天花板；C-ceiling 后手 B 已预声明 |
| **为什么 N=36** | 18 系列 × 各 2 名，Williams 过不足なく配平的最小数；a priori 功效以 SESOI 为准（非 pilot 效应量） |
| **E/D 变量太多** | 同「D-vs-E 混淆」 |
| **LLM 评价可信吗** | 质量只作**客观下限**（结构完整度）+ TOST，不进主要终点；LLM-judge 只做**盲评保真**（结构化比对，Zheng 2023 适用域）作收敛旁证，**不评创意质量**（TTCW 禁区，A1 审美 rubric 已主动弃用） |
| **怎么保证没有 HARKing** | 展示**采数前冻结**的分析计划（`prereg.py` 的 hash 化 dump + git commit）+ [05](05_分析计划冻结与试测决策树.md) 的事前声明后手树；**坦承这弱于第三方预注册**——本研究未做 OSF 预注册 |

**方法论卖点（要主动讲）**：文献 kill-review + 禁用措辞块 + 生死问题分支 + `pilot_check` 契约 = **预声明后手（非 HARKing）**框架。正是它让深度评审中大量 high 级发现被降级。
