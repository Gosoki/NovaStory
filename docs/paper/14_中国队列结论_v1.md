## 0. 结论先行

**一句话**：先提问（E）和先生成后修改（D）相比，在两个事先确定的主终点（心理所有权、意图保真）上都**没有检测到提升**，满意度也没有；E 的客观成本（token、被试时间）更高。

**三句话**：
1. **所有权**：E−D = +0.10 分（7 点量表；N = 35）。按事先冻结的判定规则，落在 ±0.5 分等价界内 → **判等价**（TOST p = .006 / .040；90% CI [−0.28, +0.47]）。但这个判定**两头都脆**：能通过的最小等价界约 0.47；BCa 自助法 90% CI 上限 +0.52 出界；剔除注意力失败 / 敷衍作答者后不通过；去掉 35 人中的某些单个被试也不通过；95% CI 上限（+0.55）超界；BF01 随先验从 2.6（r = .3）到 5.1（r = .707）。
2. **保真**：按冻结定义（主观三腿 50% + embedding 客观腿 50%），E−D = +0.11（z 分均值单位），不显著（p_holm = .67）→ INCONCLUSIVE；五种剔除口径下都不显著；embedding 客观腿本身三条件几乎一样。⚠️ 这个设计在真效应为 0 时保真 TOST 也只有约 22% 的机会通过，所以 INCONCLUSIVE 本身几乎不带信息。
3. **成本**：E 的 token 约为 D 的 2.5 倍、被试多投入约 90 秒（相对 C：约 3.6 倍、多 99 秒）。但被试并没有觉得 E 最费劲（「最费劲的一轮」选 D 的最多），负荷单题 tlx1 也没有区分。先提问确实改变了作品内容（被试选的答案被写进了终稿），但未检测到所有权的变化。

## 2. 事先确定的检验（确证性）

判定规则是事先写死的（`prereg.DECISION_BRANCHES` 2026-09-01、`primary_verdict` 2026-09-03 提交，早于首条数据）：主对比校正后显著 → 判优；不显著 → TOST（界 = `SESOI_BY_ENDPOINT`）；TOST 通过 → 等价，不通过 → INCONCLUSIVE（⛔ 不得写成「不劣」）。

模型：LMM `DV ~ 条件 + 题目 + 顺序 + (1|被试)`，三个计划对比（E−D 为主），各终点内 Holm。⚠️ 只有随机截距 = 假设三个对比共用一个标准误；实际 E 的方差更大，E−D 的 LMM 标准误对保真 / imagine / violation / 努力复合偏窄 12–18%（所有权不受影响）→ 下文凡是 LMM p 都并列配对检验 p 作复核。

### 2.1 主终点

| 终点 | 口径 | C / D / E 均值 | E−D [95% CI] | p_holm | 冻结判定 |
|---|---|---|---|---|---|
| **所有权**（own1-3 均分，7 点） | N = 35 | — | +0.10 [−0.33, +0.54] | 1.0 | **≈ 等价**（TOST ±0.5：p = .006 / .040；配对差 +0.095，90% CI [−0.28, +0.47]） |
| | N = 36 | 4.16 / 4.19 / 4.29 | +0.09 [−0.33, +0.52] | 1.0 | ≈ 等价（p = .005 / .035；90% CI [−0.27, +0.46]） |
| **保真复合**（冻结定义：主观三腿 50% + embedding 50%；单位 = 各腿 z 分的均值，不是 SD） | N = 35 | — | +0.11 [−0.07, +0.29] | .67 | **INCONCLUSIVE**（TOST 在锚题 imagine 上：E−D −0.23，不通过） |

- **主族门控**（05 §4 #6：主族 = 两主复合的 E−D，Holm）：N = 36 时 p_holm = .669 / .387，两个都没有被拒绝 → **门控关闭，所有次要终点只作描述**。
- 所有权 BF01：r = √2/2 时 5.1（N = 35 为 5.07），r = .5 时 3.8，r = .3 时 2.6，r = .2 时 2.0 → 随先验不同，**从弱到中等**支持「无差异」。
- 所有权 dz = 0.07（95% CI [−0.27, +0.42]，N = 35）。等价界 0.5 分折合 dz ≈ 0.38，CI 上限超过它 —— 所以「α = .05 的 TOST 判等价」（用 90% CI）与「95% CI 排除不了 dz ≈ 0.4」同时成立，不矛盾，但说明等价判定是边缘的。
- **设计灵敏度**（事先就能算出，体检模拟）：按冻结的端点内 Holm，N = 36 检出 dz = .48 的功效约 70%（不是文档里按未校正 α 写的 80%）；在 SESOI 处（所有权 0.5 分 ≈ dz .38）判优功效约 43%；真差为 0 时所有权 TOST 通过率约 46%、保真（imagine）约 22%。

**其他稳健性**：
- **剔除口径 V0–V4**（N = 36 上定义；V1 = 注意力题失败 9 人；V2 = ≥2 轮 straightline 9 人；V3 = 删 28 个 straightline trial；V4 = V1∪V2 共 10 人；pid 1 本来就在 V1、V2 名单里）：所有权 E−D 各口径 −0.06 到 +0.14，p_holm 全是 1.0；**TOST 只在 V0、V3 判等价，V1 / V2 / V4 都是 INCONCLUSIVE**。保真复合（50/50）E−D +0.07 到 +0.12，p_holm .58–1.0。⚠️ 剔除后 seq 0 和 seq 8 整组消失；被剔除的 10 人全部来自 09-08 场次、全部 11–20 岁；敷衍率本身随条件不同（straightline C 25% / D 17% / E 36%），但它与批次×轮次混杂（09-08 那批第 3 轮离下课只剩约 10 分钟），不能归因于条件。剔除类口径按受条件影响的行为删数据，只作附录。**正文只报 V0（及剔除 pid 1 的 N = 35），不挑口径。**
- **所有权等价判定的单点影响（两头都有）**：去掉差值 +5 的那名被试（其 E 轮全部打 7、连反向题 violation 也是 7，疑似看错锚点方向），E−D 变为 −0.05，V1 / V2 / V4 的 TOST 也都通过；反过来，去掉 36 人里 6 名 E−D ≤ −1.33 的被试中任意一人，V0 的 TOST 就不通过（p_upper ≈ .05–.06）。BCa 自助法 90% CI [−0.19, +0.51] 也不通过。
- **请求重启（技术摩擦）**：E 生成引导问题那一步不流式，被试一点屏幕请求就整个重来。碰到过重启的轮次：E 44%，C 19%，D 17%。同一个人碰到重启的那一轮，满意度 −0.57（p = .037）、imagine −0.74（p = .016），所有权 −0.26（n.s.）。控制重启后，所有权 E−D +0.21，90% CI 上限 +0.59 → 等价不再成立。⚠️ 重启发生在处理之后，控制它等于扣掉一部分 E 的设计成本，不是有效的因果修正；只作敏感性报告，主结论「未检测到提升」不变。
- **操纵检查**：03 里意向为操纵检查的 soa1（「方向由我决定」）三条件没有区分：E−D +0.19（p = .39），D−C +0.03（p = .93）。负荷单题 tlx1 也没有反映 E 多花的时间。行为层面的操纵检查通过（事前投入 +90 秒）。→ 这套每轮主观量表对条件不敏感，这是不把「等价」写成标题的又一条理由。
- **两批被试**（§1）：E−D 分批（N = 36）：所有权 +0.16（09-08）/ −0.03（其后）；imagine −0.61 / +0.46（批间差 p ≈ .04，多次检验中的单个 p）；满意度 −0.39 / +0.31；保真复合 +0.17 / +0.02。批次与讲座暴露、摩擦、年龄、序列完全共线 → 只作探索性描述，不说成「两批方向相反」。控制轮次×批次后主结论不变（所有权 E−D +0.07）。
- **题目**：保真复合有题目主效应（LRT p = .0036，来自「最后一口」那道题，不是 norming 标出的第 1 题）；条件×题目交互在 LMM 下 p = .012（所有权 .042），但只用被试内信息时不显著（.05 / .11）。题目只有 3 道且作固定效应 → 推断只及于这 3 道题（Limitations）。题目与条件完全平衡、LMM 含题目项，不造成条件偏差。
- **题目开放度（norming，2026-09-24 事后补做）**：日文三题可比；**中文第 1 题「捡到的失物」明显更同质**（gzip_cr 3.88 vs 3.34 / 3.48）。部分原因是翻译：日文 / 英文题名是「捡到的车票」，中文只写「失物」（中文基线 30 份里 25 份写钥匙、0 份写票）。
- **顺序**：条件×轮次交互全部不显著；只有 imagine 随轮次上升（+0.25/轮，未校正 p = .03）。

## 5. 探索性发现（看了数据才提出的，一律标探索性）

来源：数据挖掘报告（13 个方向、全局 FDR：约 6,300 个检验里**没有一条条件效应**活过校正；N = 36）与体检复查。只列机制线索，不能写成事先假设；**支持和反对的证据都列**：

1. **E 的「引导」基本是在 AI 预写的选项里点选**：72% 的人在引导问答环节一个字没写（创意陈述仍由本人书写）；231 个引导项中 76% 是选 AI 选项、16% 交给 AI、8% 含自己写的字；维度骨架固定，补充维度 100% 沿用 prompt 示例；第 1 题有 3 个 E trial 的问题把 prompt 示例里的「钱包」塞了进来。
2. **「选择不等于创作」的证据正反都有**：
   - 支持：镜头内本人原词越多越常被标「我的」（OR 2.3，95% CI 1.17–4.53）。
   - 没有证据：选过的 AI 选项内容是否会被标为「我的」—— OR 0.79（95% CI 0.45–1.38，只有 15 个可比 trial，检验力不足）；两个 OR 之间的差从没直接检验过。**不能写成「不跟着选过的选项走」**。
   - 反对：逐镜头「这一镜是我的想法」的占比（mine_ratio）**E 比 D 高 0.18**（p = .007），约 3/4 来自「AI 的也可以」被改标为「我的」—— 被试把选过的选项算成了自己的想法。⚠️ mine_ratio 有两个污染：E 的选项会写进脚本；E 专属的两道题紧挨在标注之前。
   - E 内「自己写过字」与「只点选」的人比，所有权更低（3.70 vs 4.53，n.s.）、SoA 边缘更低（p ≈ .03–.05），与题序混淆。
   - 近邻：Draxler 2024（Ghostwriter）已研究过「挑选」对所有权的影响（新颖性问题）；Fuchs 2010（给予决定权提高所有权）是反向文献。
3. **E 与 C 之间未检测到差异，但也无法判等价**：按 ±0.5 的 TOST，E−C 在所有权（90% CI [−0.28, +0.59]）、imagine（[−0.55, +0.11]）、满意度（[−0.51, +0.29]）上**全部不通过**；能判等价的反而是 D−C。**不能写「E 与 C 相当」**。
4. **总问卷的四道强制选择**（C:D:E，N = 35；N = 36 见括号）：最喜欢 12:10:13（12:11:13）、以后想用 9:13:13（10:13:13）、最接近心里想的 15:10:10（16:10:10）、**最费劲 7:16:12**（8:16:12）—— 全部不显著（χ² p = .18–.92），没有偏好；被试觉得最费劲的是 D 不是 E。⚠️ pid 9 的总问卷在做完三轮 4 天后（北京时间凌晨 1 点）提交，来源待核实（06 ㉔）。
5. **D 的修改入口**：2/3 的人不用；用过的 10 人共 11 条请求，其中 6 条落在输入框示例的两个主题（更搞笑 / 结局反转）上 → D 的反馈渠道被 UI 示例锚定。对大多数人来说，D 在行为上等于 C。
6. **所有权主要由个人差异和与条件无关的轮间波动决定**（条件解释的被试内方差 R²w = .005）。
7. **需求特征的剂量线索**：自报察觉程度越高，imagine 的 E−D 越大（ρ = .40）；4 名「猜到研究目的」者所有权 E−D +1.58。察觉题是再认式选项（选项里写出了操纵内容），「69% 察觉」被抬高；察觉是事后测的，可能反向因果。
8. 被试写明的意图元素在三条件下几乎全部保留（.95–.97，**单一 AI 编码（Claude），未经人工复核**）。

## 9. 局限（写进 08 §9 的清单）

1. 只有一个队列出了结果；**两批人群**（09-08 中专/职校讲座场 11–20 岁 + 其后 13 名非职校成人 21–30 岁，渠道未记录；研究不限年龄与身份），可能含未成年人（年龄档无法区分 11–17 岁）；原计划对象是日本大学生。队列 = 语言 = 人群 = 采集时间完全共线。
2. **序列按入组先后确定性分配**（不是随机），且序列表按第一个条件排序；与课堂硬截止、释放补位叠加，造成批次×序列相关。
3. 09-08 那批在施测前听了讲座（点到了 E 的立论与三个因变量），并看了研究员用三道真题目完整演示 C/D/E。
4. 按条件的流失不均：未完成者停在 E 轮的最多（9/15）→ 完成者分析里的 E 是幸存者样本（偏差方向对 E 有利）。
5. E 条件受「请求被重启」的技术摩擦更多（44% vs 17–19%），与满意度 / imagine 下降相关。
6. 注意力检查只在第 2 轮一道题，失败率 23%（8/35；N = 36 为 9/36）；无反向题，中点应答 42.9%；敷衍随轮次上升（straightline 5.6% → 30.6% → 41.7%），集中在 09-08 场次第 3 轮（离下课约 10 分钟）。
7. 保真的四条腿不收敛（α = .27）；not_against 84% 顶在 1.0；violation 紧接 tlx1、换了锚点方向；意向为操纵检查的 soa1 与负荷单题 tlx1 都没有区分条件 → 每轮主观量表对条件不敏感。
8. 题目只有 3 道且作固定效应，推断只及于这 3 道题；中文第 1 题与日文不是同一个刺激（「失物」vs「车票」），开放度偏低。
9. 机器基线和中文题面 norming 都是**采数后**补做的（同一模型快照、同一 prompt 版本，已核实）；embedding 只有一个模型。
10. 量表未经回译 / 认知访谈 / 独立预试；中国队列用自译 zh 版（own2 用「归属感」，中点标签「一般」与日文「どちらともいえない」不等价）。
11. D 的反馈框被 placeholder 示例锚定，2/3 的人不用修改入口；E 的补充维度沿用 prompt 示例（示例物件会注入第 1 题），选项顺序未随机化。
12. 每人每条件只有 1 个 trial；LMM 只有随机截距（假设复合对称）。
13. post_investment 的 LMM 落在边界解（一条 415 秒极端值）；hand_edit_chars 腿几乎退化。
14. 实测时长中位 17.5–18 分钟，超出同意书写的 10–15 分钟（约 63%）。
15. 分析集约一半的 API 请求没有完成（未记 usage），与同时在线人数高度相关、主要出在 09-08 集体场次；该场 5 人会话中断；个别 C trial 在出稿后被重跑（「只生成一次」被破坏），个别配图缺一张。
16. 没有冻结文件，没有第三方预注册；**主分析人群的改动（novice → 全样本）在 git 里晚于首批数据**；定位是看结果后定的；事先声明的 LLM-judge 盲评保真与部分敏感性分析未执行（§3、§4）。
17. 意图元素保留率等语义编码只有单一 AI 编码者（Claude），未经人工复核。
18. **一名研究员演示会话（pid 1）走了真实同意流程、被计入完成者**（待确认，06 ㉔）；另有 1 人（3 行）疑为研究员自测。研究员的后台操作不留日志。
19. 知情同意书（中国队列版）没有提到：完成页可自愿留邮箱（09-02 写入、09-03 删除）、分析阶段使用 Claude（Anthropic，美国）处理被试文本；同意书只写了 OpenAI（06 ㉔）。
20. 部分被试跨题复用同一创意、只写最低 8 字、或在 E 轮把全部引导交给 AI（不影响条件间比较，但限制了「按题创作」与「E 操纵被接受」的推论）。
21. 研究的假设、分析计划与幻灯片在公开的 GitHub 仓库里（对日本队列的需求特征风险，06 ㉔）。
