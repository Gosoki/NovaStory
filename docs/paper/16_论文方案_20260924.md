## 1. 底线：只凭中国 N = 35（日本一个人都没采到也能写成）

- **题目（问句，不出现「等価」「無効」）**：「生成前に問うことは見合うか：AI 絵コンテ作成における一発生成・生成後修正・生成前質問ワークフローの参加者内比較」／ "Does Asking First Help? A Within-Subject Comparison of Three AI Storyboarding Workflows"
- **只写四条主张**：
  1. **事先确定的检验**：E 相对 D 在所有权和保真上都没有检测到提升。所有权照报冻结判定「±0.5 分内判等价」，同一句写脆弱性（最小可通过界约 0.47；N = 35 下 BCa 90% CI [−0.22, +0.52] 不通过；去掉 35 人中 11 人里的任意一人就不通过；剔除敷衍者后不通过）。保真 INCONCLUSIVE，并说明这个设计在真差为 0 时也只有约 22% 的机会判等价（事后补算）。标签写「规则事先定、主分析人群事后改」，旧 novice 口径并列。
  2. **门控关闭、只作描述**：H3b「总投入不劣」不成立（E 净多约 90 秒）；token 高于 D（口径写清、是下界）；D 零返工 66%，触发了 07-19 写进 git 的红灯阈值（没有返工可省）；被试没觉得 E 更累。
  3. **两条行为描述**（采数前 05 §2 后手 A、§3「≈/≈ → 行为画像」就要求报）：E 的引导大多是点 AI 写好的选项；D 的修改入口多数人没用。**按 N = 35 重算并按批次拆开后再写。**
  4. **一条测量提醒**：自评保真与 embedding 客观保真几乎不相关。
- **不写**：标题 / 摘要里的「等价」；「E 不划算」；「证明无差异」；「E ≈ C」；陈述句的「选择 ≠ 创作」；任何机制主张；preregistered；randomized。
- **层级**：修论本体 + 情報処理学会 HCI 研究会研究報告（无查读，算学外发表，也能在答辩前拿到外部意见）。
- **工作量**：约 3–4 周（重算与出图约 1 周，写作 2–3 周），不需要新数据、不调 API。

## 2. 上限：不越过证据能写到的最好程度（需要日本队列）

- **形态**：两队列修论 + 一篇英文短文；毕业后两队列完整版投期刊。
- **能多写的**：两个队列都没检测到提升，合并估计把所有权差限定在 ±0.5 内（等价更稳，但标题仍不写「等价」）；成本账两国方向一致；行为与测量发现在事先预测过方向的第二队列里方向一致 → 从「纯探索」升一级（18 人只看方向，不当确证）；「先问值不值，取决于默认工作流里有没有返工可省」写成边界假设。
- **条件（缺一条就回落到底线）**：
  - A. **第一位日本被试入组前**，一次提交并推送：06 ㉒ 全部合并参数、确证归属、pid 1 剔除常量、方向预测表、合并 TOST 的中点 / 敷衍敏感性、第 6 章空表模板。**这是唯一窗口，错过补不回来。**推送前先定仓库可见性（06 ㉔-4）。
  - B. 日本满一整轮 18 人；成人、非课堂、无硬性结束时间、没听过发表；场次手工记录。
  - C. 合并门控通过。
  - D. 已有数据上的补分析：N = 35 全量重算（✅ 2026-09-30 已完成，见 14）；71% 等过程数字按批次 / E 所在轮次 / 是否 straightline 拆开；mine_ratio 与所有权的差中差；mine_ratio 污染界定；中点混入的 TOST 模拟；本地多模型 embedding 复核（不调 API、不外发文本）。
  - E. 文献核实：APE 全文（对照组迭代怎么定义、对齐怎么测）、Maier（01 与 reference 记录矛盾；d = 0.57 比的是 human-led vs model-led，不是问与不问）、Draxler 2024 挑选臂数值、《Optimized but Unowned》原文。
- **层级**：修论高评价；CHI 2027 Posters；毕业后 IJHCI（优先）/ IJHCS / IUI 2028。
- **上限也不能写**：「先问无效」的普适结论；机制因果；超出「短篇、低投入、非专家 AI 分镜」的推广。

## 3. 修论结构（日语；F4 骨架 + F1 主线）

1. 序論：RQ 保持采数前原样；原「灵魂句」降为「受检验、在本设置下未获支持的设计主张」
2. 関連研究（APE / Maier / GATE / CollabLLM / IntentFlow / Draxler 的切割表）
3. NovaStory：只写做了什么、为什么这样做，不评价效果
4. 方法：含「事先确定的边界」时间线表；写明非随机分配（按入组先后）、两批被试
5. 実験1 中国コホート：F1 的确证检验 + 成本 + H3b + 两条行为描述
6. 実験2 日本コホートと統合：**日本数据进库前先提交空表模板**
7. 考察：①这个零排除了什么、没排除什么；②为什么与 APE / Maier 不同（全标探索性）；③F2 的命题表（支持 / 反对 / 缺什么）作设计启示；④F3 压成一节「測定の限界」（soa1 / tlx1 不动、主客观不收敛、锚点两难、中点作答对 TOST 反保守）
8. 研究過程の省察と限界：约 5 页，写成方法学教训，不写成检讨书
9. 結論

**写作顺序**（先写不依赖结果的章）：第 4 章 → 第 3 章 → 第 5 章（从 14 改写）→ 第 2 章 → 第 8 章 →（日本进库后）第 6、7 章 → 第 1 章与摘要。会议稿从修论里裁，不反过来；同一数据出多篇要互相引用、写明重叠。

## 4. 答辩最可能被问倒的五点（按危险程度）

1. 「量表连 soa1 这道操纵检查都没反应，你的零是没效果还是测不出来？」—— 最危险，只能部分回答：行为层操纵检查通过、embedding 客观腿同样是零、强制选择也没有偏好；但测量不灵敏排除不了 → 结论限定为「用这套测量没检测到」。
2. 「D 有 2/3 的人不改，你其实是拿 E 和一次成型比；而 E 和 C 之间又判不了等价。」
3. 「去掉 35 人里 11 人中的任意一人等价就不成立，这还叫等价？」—— 主句始终写「未检测到提升」，冻结判定照报并紧接脆弱性。
4. 「日本的修论，主数据为什么是中国 11–20 岁的职校生？而且他们施测前听过讲座、看过演示。」
5. 「定位是看结果才定的，人群口径采数后才改，是不是 HARKing？」—— 拿出 05 §3 四象限矩阵的「≈ / ≈」格（git 07-18 / 08-03）和 14 §3 的时间线表。

## 5. 日本数据两种情况下怎么改写（规则进库前写死，看了结果不换）

- **确证归属（三位评审一致建议）**：**中国 N = 35 为确证；合并为事先提交的精度估计；日本单独只作描述与方向复核**。理由：合并参数是看过中国结果后才定的，合并分析并不比中国单队列更干净。（06 ㉒-7 原草案是「合并为唯一确证」，两者必须二选一。）
- **一致**：主句仍是「未检测到提升」，可加「两个队列都没检测到，合并估计把所有权差限定在 ±0.5 内」；行为 / 测量发现升为「在事先预测方向的第二队列中方向一致」；同时报日本中点率与剔除敷衍后的 TOST（日本中点作答更多会让合并 TOST 更容易通过）；不能说「跨文化稳健」（队列 = 语言 = 人群 = 时间共线）。
- **不一致**：
  - 日本 E−D 明显为正：确证仍是中国的「未检测到」；日本只写「18 人上方向为正，无法确认」；考察写「可能依赖人群或情境」的探索性假设；**严禁补招人去把它做显著**。
  - 日本 E−D 为负：照报，同时看 E 的请求重启率（摩擦敏感性）。
  - 主效应一致、行为不一致（日本人自己写得多、D 改得多）：「菜单化」「D 不改」收窄为「中国队列、课堂情境下的现象」；「没有返工可省」的解释要降级。
  - 日本不满 18 人：合并降为探索性，全文退回底线方案。
- 两种情况都不变：H3b 不成立、成本更高、自评与客观保真不收敛照报；方向预测成败都报；E−C 只写「未检测到差异」。
