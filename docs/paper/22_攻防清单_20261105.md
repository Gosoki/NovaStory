### 0.2 发表前必改的事实错误（1、2 亲自核对过原文；3 亲自推导并在数据上算过）

1. **S6 大字「約41%：指示にないところを、AI が正しく補えた割合」—— 含义不对。**

   - 引言明写 *"This issue is less significant for end users… For LLM application developers, the problem is much more serious"* —— **作者说这对终端用户问题较小，而 deck 正是拿它讲终端用户**。

   - **改法**：去掉大字；或改成「指示にない要件をほぼ確実に（98% 以上）満たせたのは約 4 割（開発者向けプロンプトの研究）」，并说明是类推。

2. **S6 标题「『まず作らせ、あとで直す』が一般的¹」与笔记「複数回のやりとりが多い」—— 依据不支持。**
   - WildChat §3：*"approximately 41% of conversations contain multiple turns"*，即约 59% 是单轮；多轮也没有被分类成「修改」。「指示不够明确所以要多轮」只是 Appendix C 的定性观察。

   - **改法**：标题弱化（「作らせてから直す使い方がよく行われる」），笔记改成「多轮对话约 4 成；没有找到『先做后改』占比的数据」。

3. **A1「手法3と手法2の比較に順番の影響が混ざらないようにする」、S17 笔记「持ち越しの影響を打ち消す」—— 统计上过强。**

### F3 · 「意図への忠実性」到底测到了吗？

- **问**：「4 つの指標は同じものを測っていますか」「『思い描いた映像に近いか』は満足度と何が違うのですか」「質問されたあとで、はじめの意図を正しく思い出せますか」「文章の近さで意図が分かりますか」
- **证据**：
  - 判定变量 ≠ 主终点：等价检验做在 imagine 上（`prereg.EQUIV_DV_BY_ENDPOINT`），S20 同屏 +0.11 与 −0.23。✅ 笔记已解释方向，但没有下面这些。
  - **+0.11 的约 85% 来自 violation 一道题（新算）**：violation +0.090、not_against +0.039、embedding +0.004、imagine −0.028。去掉 violation 后复合 E−D 只剩 +0.02（配对 p = .84）。而 violation 偏离的是 D（3.94 vs C 3.31、E 3.20），E 与 C 一样。
  - **「半分＋半分」只是名义上的（新算）**：复合的方差约 2/3（67%）来自 embedding，因为主观三腿先平均、方差被压小；而均值差约 85% 来自 violation。**噪声主要来自一条腿，信号主要来自另一条腿。**
  - **两道核心题更像别的构念（新算）**：imagine–满意度 r = .83；violation–tlx1 r = .45（紧跟 tlx1、第一次换方向）；imagine–violation r = −.09（被试内 +.03）；105 个 trial 里 51 个两题同数；9 个 trial 同时 imagine ≥ 5 且 violation ≥ 5，6 个在 D。
  - 四腿 α = .27（✅ 笔记）；not_against 85% 顶格（「主に AI だが納得」也算忠实）；embedding 与 imagine 被试内 r = −.29，方向相反（14 §2.4）。

- **答**：「忠実性は一つの尺度で測れると仮定せず、自己評価と文章の近さを事前に半分ずつと決めました。結果として指標は一致せず（α = .27）、これ自体が結果です。合成得点ではなく指標ごとに読みます。」不要替复合辩护，主动拆开讲；被问 +0.11 就说「主に『意図に反する』の差で、それは手法2 が高かったためです」。
- **补**：备用页放四腿分解；修论按腿报告。
