## 论证链：为什么这个研究有用（第 1 章可以照这个顺序写）

1. **生成式 AI 让新手也能创作**，但效果因人而异（01 §1）。
2. **新手说不清自己想要什么**：提示词机会主义、构想与输出之间有鸿沟（01 §2）。
3. **没说的部分，AI 用默认值补上**，作品趋同、不像自己想的（01 §3、04）。
4. **两种补救思路**：一是「先生成、再修改」（今天最常见的用法）；二是「生成之前先问清楚」。后者已有正面的先行证据（文生图、偏好引出、代码），也有理论依据（偏好构建、作者感的「想法先于行为」），业界也已把它做成默认行为（02 §1–§4）。
5. **但缺一个关键检验**：在创作类作品、针对新手、直接和「先生成再修改」对照，同时测所有权与意图保真的真人实验（02 §5）。2026 年出现了几个近邻（上表），但任务、人群或条件都不同；而且其中几项在所有权 / 意图反映上同样没有检出差异。
6. **本研究就是这个检验**。结果：在中国队列 35 人中，E 没有提升所有权与保真（与 D 判等价 / 无法判定），成本更高；但 E 的作品更不像模型的默认写法（探索性）。06 的边界条件（所有权取决于谁执笔、点选≈接受推荐、提问的时机与质量、新手要看到产物才形成意图、自评量表不敏感）给出解释，06 §7 列了讨论章节可以直接用的 6 条论证线；日本队列用来复核。
